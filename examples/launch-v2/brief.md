# Make the next thing move

A 15-second Motion Mania brand film for builders. One graphic object becomes a code surface, an animated composition, a review frame, and an export. Connected transformations make the production process tangible.

Direction: oversized editorial typography, near-black, warm paper, vivid orange; purposeful match moves and one dominant visual per beat. Full HD landscape and portrait, each composed independently. Retain local fonts and self-contained assets.

Copy: MAKE / IT MOVE. → A LITTLE CODE. → A LOT OF MOTION. → LOOK AGAIN. → EVERY FORMAT. → MOTION MANIA.

Audio: an original electronic pulse with bass, restrained percussion, stereo detail, transition sweeps, and a resolved final chord. Normalize to -16 LUFS and -1.5 dBTP; verify measurements without claiming listening review.

The code and geometric motion are designed illustrations of the toolkit workflow, not footage of a GUI. Preserve v1 for comparison. Toolkit improvements developed alongside this film belong in the shared CLI and skill.
