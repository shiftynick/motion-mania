# Security

Report a vulnerability privately through [GitHub security advisories](https://github.com/shiftynick/motion-mania/security/advisories/new). Avoid public issues containing credentials, private assets, or exploitable details before a fix is available.

The latest published version is supported. This is an early project; no response-time SLA is promised.

Motion Mania renders executable HTML/JavaScript through HyperFrames. Treat projects as code: inspect untrusted source and use an isolated environment. This tool is not a security sandbox. Generated projects are local, but authored HTML can make network requests. Rendering artifacts may contain product or customer data; decide what to share before attaching them to an issue.
